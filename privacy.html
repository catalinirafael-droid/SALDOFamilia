Política de Privacidade — SALDOFamília

🛡️ Segurança em primeiro lugar: o aplicativo foi projetado com autenticação, isolamento de dados por família e controles de acesso no banco.

Última atualização: 29/08/2026

1. Dados tratados

O SALDOFamília armazena os dados que você fornece para usar o aplicativo, como e-mail, nome, lançamentos financeiros, categorias, metas, contas, cartões, compromissos e dados de família compartilhada.

2. Finalidade

Os dados são utilizados para autenticação, sincronização entre dispositivos e pessoas autorizadas da mesma família, geração de relatórios e funcionamento dos recursos do aplicativo.

3. Infraestrutura

A versão atual utiliza Supabase para autenticação e armazenamento. O acesso ao banco é protegido por regras de Row Level Security (RLS), que aplicam permissões no próprio banco de dados.

4. Compartilhamento

Dados financeiros de uma família são visíveis apenas às contas autorizadas a participar daquela família, conforme as permissões implementadas.

5. Backup

O usuário pode exportar dados em JSON e transações em CSV. Arquivos exportados ficam sob responsabilidade do usuário.

6. Segurança

O aplicativo não inclui chaves administrativas do banco no navegador. Apesar das medidas técnicas, nenhum sistema conectado à internet pode garantir segurança absoluta.

7. Direitos e exclusão

Para uma publicação pública, disponibilize um canal de contato para solicitações de acesso, correção ou exclusão de dados e ajuste este texto conforme sua operação real e a legislação aplicável.
